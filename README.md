# На глаз

Русскоязычная браузерная игра в стиле Fermi. В каждом выпуске три бытовых вопроса на прикидку, по одной попытке на вопрос. Результат — среднее трёх множителей ошибки.

Откройте `index.html` в браузере. Для запуска через HTTP откройте терминал в этой папке и выполните:

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

Адрес игры — `http://127.0.0.1:8765/`. Прогресс и результаты хранятся в текущем браузере.

Семь выпусков на 12–18 ноября 2026 года находятся в `questions.js`. Добавляйте новые выпуски в конец массива по порядку дат. Игра открывает их по московскому времени и сохраняет прошлые в архиве.

## Развёртывание на Amvera

Amvera собирает корневой `Dockerfile`. Контейнер раздаёт файлы игры через nginx на порту 80. Дополнительный файл `amvera.yaml`, база данных и переменные окружения не нужны.

1. Создайте приложение в Amvera и скопируйте URL Git-репозитория из вкладки «Репозиторий».
2. Из локальной папки проекта добавьте этот адрес как отдельный Git remote и отправьте ветку из GitHub. Замените пример URL на адрес из кабинета.

   ```sh
   git remote add amvera "https://git.amvera.ru/USERNAME/PROJECT"
   git push amvera main:master
   ```

3. После сборки добавьте бесплатный домен Amvera во вкладке «Домены» и выберите HTTPS.

Для автоматического развёртывания после каждого push можно [подключить репозиторий GitHub через вебхук](https://docs.amvera.ru/applications/git/webhooks.html). Ручная отправка описана в [инструкции Amvera по подключению существующего репозитория](https://docs.amvera.ru/applications/git/secondary-origin.html).
